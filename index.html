DESKTOP CONTROL

Your AI desktop agent.

Orbit can capture your desktop, open files and URLs, and execute approved actions. Desktop control is disabled by default and requires explicit activation.

🤖

Agent status

Checking…

Enable desktop control

Add DESKTOP_CONTROL_ENABLED=true to your .env file and restart the server.

Security model

All desktop actions require a per-session token. Actions are confined to approved types: open URL, open file, screenshot, click, type.

Sensitive actions

Sending emails, deleting files, form submissions, and account changes require separate explicit confirmation.

What is NOT supported

Silent background monitoring, credential extraction, unrestricted shell execution, or access outside the project folder.
